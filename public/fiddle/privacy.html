Privacy policy

Last updated September 26, 2026

Tune Book (nategrimwood.com/fiddle) is Nate Grimwood's personal fiddle tune list. Anyone can read it. Only its owner can sign in and edit it.

Visitors

If you're just reading, the site doesn't ask for or store any personal information and sets no cookies. Cloudflare, which hosts the site, keeps standard technical logs (such as IP addresses) for security and reliability.

Signing in

Sign-in is only for the owner. When you use "Sign in with Google", the site receives your Google account's email address and checks whether it's the owner's. If it isn't, nothing is stored. Passkeys, if added, store only a public key and a device label. A sign-in cookie keeps the owner signed in; it's used for nothing else.

Google Drive

With the owner's permission, the site reads files in the owner's own Drive "Fiddle" folder (recordings, sheet music and videos) so it can list and play them, and saves audio-only copies of videos into a folder there. It stores file names, sizes and links in its database. It does not access anyone else's Drive, and it does not read other files except to find that folder.

Tune Book's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data from Google is used only to run these features for the owner. It isn't sold, used for advertising, or shared with anyone, and no one else reads it.

Where data lives

The tune list and file index are kept in a Cloudflare D1 database. Recordings stay in Google Drive and are passed through to the owner's browser when played.

Removing access

The owner can turn off Drive saving on the site ("Stop saving") and revoke the app at myaccount.google.com/permissions.
